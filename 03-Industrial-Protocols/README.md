# Module 03: Industrial Protocols

This repository contains RTL design implementations, bus architectures, and verification testbenches for standard industrial communication protocols and on-chip interconnects.

---

## 📌 Overview

This module covers various industry-standard on-chip bus protocols, memory transfer controllers, and flow control mechanisms essential for SoC (System-on-Chip) and digital system design.

### Key Areas Covered:
- **On-Chip Bus Protocols**: Standard bus architectures (e.g., AMBA protocols) for interfacing processors, memory, and peripheral cores.
- **Data Transfer & Flow Control**: Handshaking mechanisms and controllers (e.g., DMA) for high-speed, synchronized data exchange.
- **Verification**: Functional simulation and testbenches to validate protocol compliance, timing, and data integrity.

---

## 🛠️ Tools & Languages
- **HDL**: Verilog 
- **EDA & Simulation**: QuestaSim / ModelSim / Icarus Verilog
